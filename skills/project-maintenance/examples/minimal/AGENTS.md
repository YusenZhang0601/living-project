# 示例项目协议

> 这是 project-maintenance 的最小示例。**本文件只放结构、规则、指针**：不记知识、不记流水、不记教程。
> 它每轮都进上下文，所以必须短。

## 现状（一屏）

- 支线 1 条：`todo/`（进行中）
- 下一步：把 `docs/STATUS.md` 的下一步做完，然后跑 `check.sh`

## 启动

1. 本文件（已加载）
2. `docs/STATUS.md` —— 整体现状
3. `todo/STATE.md` —— 目标分支现状

## 规则

1. 汇总与索引由脚本生成，不手改。
2. 一条知识一个 owner；被推翻的标取代，不删。
3. 收工前跑 `check.sh`，不绿不算完。

## 去哪问

| 想知道 | 读 |
|---|---|
| 现在进展 | `docs/STATUS.md` |
| 最近的裁决 | `docs/DECISIONS.md` |
| 这条线具体到哪一步 | `todo/STATE.md` |

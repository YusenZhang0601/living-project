# 项目维护 · 一次交接的例子

假设一个小工具已经有项目入口和状态页。上一轮结束时，会话说「导入差不多好了，下一轮继续优化」。只读项目文件的接手者不知道哪条路径已验证、哪里失败，也无法判断后续工作的优先级。

**交接后，现有状态页的一段记录可以是这样。**

> TSV 导入的三份普通样例已通过，结果记录在 `tests/import/README.md`。带引号且含制表符的字段仍然解析错误，复现样例是 `tests/import/quoted-field.tsv`。下一步用这份样例修复解析，验收以字段值读回正确、旧样例仍通过为准。先读 `tests/import/README.md`，里面有运行测试的命令。

项目入口继续指向原来的状态页。新会话现在能找到当前结果、卡点、下一步和先读的来源。例子中的路径和记录是示意，实际交接须以项目可回查的结果填写。

更多用法见 [SKILL.md](SKILL.md)。

# 给项目的生长校准方向

项目持续生长，路径会随证据变化。漂移检查关心的是，最近长出来的东西有没有让目标更近、让必要条件更成熟，或减少会改变决策的不确定性。代码、文档、理论、测试和维护都可以推进目标，也都可能消耗精力却碰不到真正的问题。判断依据是它们对目标造成的实际变化。

## 用目标理解变化

**沿用负责人确认的目标。** 可以用用户已经明确的目标，或项目指定且仍有效的目标来源。说清要实现或回答什么，以及什么结果能说明它更接近了。负责人可以根据新证据改变目标或定下新的阶段边界。当前活动和汇报用词本身不足以说明目标变了。目标缺失、冲突或含糊到会改变判断时，再确认或给出有明确假设的条件性结论。

**看与目标有关的真实证据。** 选能回答本次问题的近期工作，结合实际产物、结果、推导或反馈。哪项工作直接推进了目标？哪项解决了前置条件？延后其中某项，哪条验收路径会晚、哪个风险会上升，或者哪个问题仍答不出来？证据只能说明有多少项工作时，就按项说明。解释投入时间或成本要有相应记录。

**留意手段开始取代目的的时候。** 例如设计反复叠层却没触到关键障碍，把辅助产物当作已经实现的结果，或为了治理而改造运转有效的结构。提交数、文档增长、同层推进等可以提示回看。连续完成理论闭合、排除一个关键假设或修正会影响验收的可靠性问题，即使没有增加新功能，也可以是实质进展。

## 用结论决定下一步

- **方向一致**。指出取得的进展或正在解决的必要条件，给一个继续动作和可观察结果。
- **确有漂移**。指出哪项工作消耗投入、延后又不会妨碍目标。证据足够时，优先建议暂停或冻结影响最大的一项，说明何时值得恢复，并给出一个真正推进或检验目标的动作。
- **证据不足**。点出会改变判断的未知，选一个最有区分力的观察、核对或实验，说明不同结果分别支持什么决定。

下一步取决于项目实际要产出什么。应用可以验证一条从真实输入到用户结果的路径，科研可以解决决定性的闭合或做区分解释的对照，内容可以检验关键论据或读者能否按文档完成任务。每项关键判断指向可回查的证据。需要独立复核的高影响判断，让复核者先依据目标和原始材料形成看法，再比对理由。

检查保持只读。把目标、结论、关键证据和下一步交给负责人，由负责人决定是否停项或改变方向。
